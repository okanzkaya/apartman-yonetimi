🚀 Frontend Ekibi İçin API Kullanım Rehberi
Frontend geliştiricilerinin React/HTML tarafında fetch() veya axios ile istek atacağı adresler (Endpointler) ve göndermeleri gereken veri isimleri aşağıdadır. (Bu değişken isimlerine harfiyen uymaları şarttır!)

1. Giriş İşlemleri (Auth)
Adres: POST http://localhost:5000/api/auth/login

Gönderilecek JSON Verisi:

JSON
{ "email": "ahmet@gmail.com", "sifre": "1234" }
Backend'in Vereceği Yanıt: Kullanıcı bilgileri ve "Rol" (Yönetici/Sakin) döner.

2. Duyuru Sistemi
Duyuruları Getir (GET): http://localhost:5000/api/duyurular/1 (Sondaki 1, apartman_id'dir)

Duyuru Ekle (POST): http://localhost:5000/api/duyurular

Gönderilecek JSON Verisi:

JSON
{ "icerik": "Asansör bakımı var", "apartman_id": 1 }
3. Aidat Sistemi
Borçları Getir (GET): http://localhost:5000/api/aidat/1 (Sondaki 1, daire_id'dir)

Aidatları Toplu Hesapla (POST): http://localhost:5000/api/aidat/hesapla

(Not: Hesapla butonu için veri göndermeye gerek yoktur, direkt SQL prosedürünü tetikler.)

4. Arıza Sistemi
Tüm Arızaları Getir (GET): http://localhost:5000/api/ariza

Yeni Arıza Bildir (POST): http://localhost:5000/api/ariza

Gönderilecek JSON Verisi:

JSON
{ "daire_id": 1, "aciklama": "Su borusu patladı" }
